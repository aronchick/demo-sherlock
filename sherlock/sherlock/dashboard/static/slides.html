03 / From close-up to a case

A closer look.
An accountable decision.

Check the object

Only the masked object crop reaches the vision models. The Verifier checks the claim first; the Analyst then adds a description.

Keep the human in the loop

Review the camera identifier and pictures on the phone. Investigate, record a team notification, then resolve.

Evidence record

Trace it back.

Original scene and object evidence stay linked. A confirmed alert also retains an available face crop for human review.

Local Ed25519 signatures, image hashes and a revision chain make changes inspectable.

04 / The serving stack

Small tickets.
Purpose-built model calls.

NVIDIA Brev runs the models. Expanso carries the incident data.

Red Hat AI · FP8Nemotron 3.5 Lightning checkpoint, quantized with LLM Compressor.

vLLM · ServingTool-call API for the Director. Image requests for SmolVLM.

Expanso · TransportIncident events and evidence with inspectable downstream receipt.

FP8 reduces storage per quantized weight. Latency and delivery are verified from the run.
