# Evaluation records

These are historical measurements, not a statement of current deployment health.
Benchmark and Scout records retain their measured results, including failures,
model identifiers, input hashes, and evaluation limitations.

Machine-specific absolute path prefixes have been removed for publication.
Paths under `data/` and `runs/` identify files in the original evaluation
workspace; those private room images and training outputs are not distributed.
The selected checkpoint is bundled under `models/`. See
[Scout validation](../docs/SCOUT_R2_VALIDATION.md) for the split limitations.
